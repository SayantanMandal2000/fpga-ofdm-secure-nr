# Contributing

## Ground rules

- **Model first.** Every change to the RTL arithmetic goes into `src/ofdm_model` first, with a unit test in `tests/`.
- **Golden values.** When an RTL change alters a register value, a coefficient or a table, update the golden tests (`tests/test_pc_coef.py`, `tests/test_rtl_consistency.py`).
- **Generated files.** `rtl/sincos_lut.v` is generated by `scripts/gen_sincos_lut.py`; do not edit it by hand.
- **Report results as measured.** Failing tests and model-only results stay labelled as such.

## Before opening a pull request

```sh
make test lint sim-fft      # must pass
make sim-top                # attach build/tb_top.log if RTL behaviour changed
make results                # if a model or experiment changed; commit results/ and docs/figures/
```

## Style

- Verilog-2001, one module per file, file name = module name, `timescale 1ns / 1ps`, active-low `rst_n`, synchronous logic on `posedge clk`.
- Fixed-point formats are stated in a comment at each declaration (for example `// Q2.14`).
- Python: `ruff check src tests experiments` must be clean. The model deliberately mirrors the RTL line by line.
- Commit messages: imperative mood, a scope prefix (`rtl:`, `tb:`, `model:`, `docs:`, `ci:`).
